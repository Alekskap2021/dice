# Кости

Аналог игры в кости из Kingdom Come: Deliverance. Браузер, TypeScript, Three.js, Node.js + WebSocket.

## Запуск

```bash
npm install
npm run dev        # клиент http://localhost:5173, сервер :3000
```

Продакшен: `npm run build && npm start` — сервер на `:3000` отдаёт и клиент, и WebSocket (`PORT` меняет порт).
Для игры с другом по интернету сервер нужно выложить на хостинг с поддержкой WebSocket (Fly.io, Railway, VPS).

## Возможности

- Игра с ботом и по сети: создать комнату, отправить ссылку-приглашение или четырёхбуквенный код.
- Цель партии (очки) выбирается перед стартом.
- Правила в игре (кнопка `?`), табло с очками, прогрессом и текущим ходом, журнал событий.
- 3D-кубики, анимация броска, звуки (синтезируются Web Audio, файлов нет) и фоновая мелодия.

## Структура

- `shared/rules.ts` — таблица очков и подсчёт комбинаций. Все числа правил здесь.
- `shared/engine.ts` — состояние партии и ходы. Работает и на сервере, и у бота в браузере.
- `shared/bot.ts` — бот.
- `server/index.ts` — комнаты; кубики бросает сервер, поэтому сжульничать нельзя.
- `client/src` — сцена (`dice3d.ts`), звук (`audio.ts`), сессии (`session.ts`), интерфейс (`main.ts`).

`npm test` — тесты движка, `npm run typecheck` — проверка типов.
